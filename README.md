# projeto arduino criado em aula - SENAI
Projeto desenvolvido durante uma aula de IoT, no curso de Desenvolvimento de Sistemas do SENAI São Paulo.

## descrição

```bash
Este programa faz o Arduino Uno ligar e desligar (piscar) os pino 7 e 8 e, nos quais possuem LEDs ligados em si, sendo eles das cores azul e vermelha, fazendo com que o piscar se assemelhe ao giroflex de um carro de polícia.
```
